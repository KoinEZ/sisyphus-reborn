# Русификатор Sisyphus Reborn

[Интересная история](https://store.steampowered.com/app/517910/Sisyphus_Reborn/), прохождение на фулл концовки со всеми ачивками заняло всего 60 минут. Рекомендую ознакомиться, тем более игра распространяется бесплатно.
По технической части: новый для меня движок, без пересборки .exe игра давала всего 23кб памяти на шрифт. Нашёл более-менее органично вписывающийся, очень сильно его ужал, вырезал все лишние символы, но всё-таки запихнул. 

[`Sisyphus.Reborn.RU.1.0.zip`](Sisyphus.Reborn.RU.1.0.zip)
Что сделано:

- Описания комнат и предметов, реплики, заголовки, меню
- Шрифты адаптированы под кириллицу

Установка:

- Скачать архив
- Распаковать содержимое в папку с игрой (шрифты должны быть рядом с .exe) и запустить файл "Установить русификатор"
